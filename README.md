# Road to C&O 100

Jeffry's running and strength plan from Nov 23, 2026 to the C&O Canal 100 on Apr 24, 2027, with a log for every run and every lift.

- Hosted on GitHub Pages. Open it in Safari on iPhone, tap Share, then "Add to Home Screen".
- Logged runs and lifts are saved on the phone only. Use Backup in the app to export them.
- The plan lives in `data.js`. Weeks 8 and later get added there before Jan 11.
- Exercise photos are optional: save them as `images/<exercise id>.jpg` (see `image-prompts.md`).
- After changing core files, bump `CACHE` in `sw.js` so phones load the new version.

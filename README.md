# Road to C&O 100

Jeffry's 22-week plan from Nov 23, 2026 to the C&O Canal 100 on Apr 24, 2027: what to run each day and what to lift.

- Hosted on GitHub Pages. Open it in Safari on iPhone, tap Share, then "Add to Home Screen".
- Running is a read-only weekly view: session, miles, and Easy / Hard / Race / Rest.
- Workout has one weight box per exercise. Weights are saved on the phone only.
- The plan lives in `data.js`.
- Exercise photos: `images/<exercise id>.jpg` (1000 px wide) plus `images/thumbs/<exercise id>.jpg` (240×180), and the id added to `PHOTOS` in `data.js`. Prompts are in `image-prompts.md`.
- After changing core files, bump `CACHE` in `sw.js` so phones load the new version.
